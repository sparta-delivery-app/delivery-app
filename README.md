# 아웃소싱 프로젝트: 배달 애플리케이션 구현
사장은 자신의 가게를 운영하고, 사용자는 간편하게 음식을 주문할 수 있는 배달 애플리케이션을 개발하는 프로젝트입니다.

<br>

## 프로젝트 목표
1. 인증과 인가의 개념을 이해하고, JWT를 활용한 로그인 시스템을 구현한다.
2. JPA를 활용한 CRUD 구현 능력을 향상시킨다.
3. Git을 활용하여 협업하는 능력을 향상시킨다.
4. 안정적인 애플리케이션 개발을 위한 테스트 코드 작성을 연습한다.

<br>

## 기술 스택
- **언어**: Java
- **프레임워크**: Spring Boot
- **ORM**: JPA
- **인증/인가**: JWT
- **버전 관리**: GitHub
- **클라우드 스토리지**: AWS S3

## 주요 기능
### 사용자 계정 관리
1. **회원가입**: USER, OWNER 권한을 구분하여 회원가입을 진행한다.
2. **로그인**: 사용자가 입력한 인증 정보를 검증한 후 JWT를 발급한다.

### 가게 관리
1. **가게 CRUD**: 사용자는 가게를 생성/수정/조회/삭제할 수 있다.
2. **권한 확인**: OWNER 권한의 사용자만 가게를 생성/수정/삭제할 수 있다.
3. **페이지네이션 적용**: 가게 전체 조회 시 페이지네이션을 적용한다.
4. **SOFT DELETE 적용**: 가게 삭제 시 데이터를 물리적으로 삭제하지 않고 비활성화 상태로 변경한다.

### 메뉴 관리
1. **메뉴 CRUD**: 사용자는 메뉴를 생성/수정/조회/삭제할 수 있다.
2. **메뉴 옵션 CRUD**: 사용자는 메뉴 옵션을 생성/수정/조회/삭제할 수 있다.
3. **권한 확인**: OWNER 권한의 사용자만 메뉴와 메뉴 옵션을 생성/수정/삭제할 수 있다.
4. **메뉴 이미지 관리**: Spring Cloud AWS가 제공하는 S3Template을 이용하여 이미지 업로드 및 삭제를 구현하였다.

### 리뷰 관리
1. **리뷰 CRUD**: 사용자는 리뷰를 생성/조회/수정/삭제할 수 있다.
2. **권한 확인**: 자신이 작성한 리뷰에 대해 생성/수정/삭제할 수 있다.
3. **주문 상태 확인**: 사용자는 배달이 완료된 주문에 대해 리뷰를 작성할 수 있다.
4. **페이지네이션 적용**: 사용자는 특정 가게의 리뷰를 최신순, 별점 범위를 기준으로 조회할 수 있으며, 페이지네이션을 적용하였다.

### 장바구니 관리
1. **장바구니 담기**: 사용자는 한 가게의 메뉴들을 장바구니에 담을 수 있다.
2. **장바구니 내역 조회**: 사용자는 장바구니에 담긴 메뉴 목록을 조회할 수 있다.
3. **장바구니 내역 삭제**: 사용자는 장바구니에 담긴 메뉴를 삭제할 수 있다.

### 주문 기능
1. **주문하기**: 사용자는 장바구니에 담은 메뉴들을 주문할 수 있다.
2. **주문 내역 조회**: 사용자는 자신이 주문한 주문 내역을 조회할 수 있다.
3. **주문 내역 가게별 조회**: 사장은 자신의 가게에 들어온 주문 내역을 조회할 수 있다.
4. **주문 상태 변경**: 사용자는 주문 취소를 할 수 있고, 사장은 주문 거절/주문 수락/배달 시작/배달 완료 순서로 주문 상태를 변경할 수 있다. AOP를 통해 상태 변경 시 로그가 출력된다.
